# Media

Drop the round-trip demo here as **`round-trip.gif`**, then uncomment the image line near the top
of the repo [README](../../README.md).

**Suggested capture (~10–15s):** mirror a doc to the tablet (`./sync.sh mirror`), hand-annotate it
(tick a checkbox, strike a line, add a margin note), run `./sync.sh process`, and show the source
Markdown updating in the editor. Keep it short and loopable.
